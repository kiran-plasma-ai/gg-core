# gg-core Registry

Complete architecture overview of gg-core - a minimal Python library for tmux-based AI agent session management.

> **AGENT INSTRUCTION**: When working on gg-core, prefer using the core library functions (start_session, send_command, etc.) over CLI commands for programmatic access. Follow the module structure documented below.

## CLI Commands

| Command | Description |
|---------|-------------|
| `start` | Start a new session |
| `stop` | Stop a session |
| `ps` | List all sessions |
| `send` | Send a command to a session |
| `logs` | Show session logs |
| `attach` | Attach to a session |
| `connect` | Start and attach to a session |
| `doctor` | Check gg-core installation health |
